# Conversational-Data-Analytics

# AI-Driven Conversational System for Automated Data Analysis

An AI-powered web application that allows users to upload Excel or CSV files and interact with their data using natural language queries. The system automatically analyzes datasets, generates insights, and creates visual reports without requiring SQL queries or Python scripting knowledge.

---

## Features

- Upload and analyze CSV/Excel datasets
- Natural language-based data querying
- AI-powered response generation using Llama 3.3 70B
- Automated data preprocessing and cleaning
- Dynamic Pandas code generation and execution
- Interactive analytical reports and chart visualizations
- User-friendly and responsive interface
- Supports non-technical users for automated data analysis

---

## Tech Stack

### Backend
- Python
- Flask
- Pandas

### Frontend
- HTML
- Tailwind CSS
- JavaScript

### AI Integration
- Groq API
- Llama 3.3 70B Model

---

## How It Works

1. Users upload an Excel or CSV dataset.
2. The user enters a query in natural language.
3. The system sends the query to the AI model through the Groq API.
4. The AI generates dynamic Pandas-based analysis code.
5. The backend processes the dataset and returns analytical insights or visualizations.
